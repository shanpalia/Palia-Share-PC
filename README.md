# Palia Share for Windows PC

**Palia Share by PaliaWin Store**  
**Developer by Shanpalia**

Windows PC companion for Palia Share. The PC app will support fast local file transfer with Android devices and other PCs.

## Planned build
- Nearby device discovery
- Android ↔ Windows transfer
- Windows ↔ Windows transfer
- Accept / Reject incoming files
- Transfer progress and speed
- Palia Share branding and icon
- Proper Windows installer: `Palia Share Setup.exe`
